# Інструкція для стейкхолдера: Ambassador Program Automation

## Коротко про проєкт

Цей проєкт автоматизує збір активностей студентських амбасадорів, підрахунок coins і щомісячні Slack-нагадування/звіти.

Основний сценарій такий:

1. Амбасадор відкриває форму й заповнює activity report за потрібний місяць.
2. У формі він вказує ім'я, Slack nickname, місяць, типи активностей, кількість і додає proof-файли там, де вони потрібні.
3. Backend перевіряє дані, рахує coins і бонус.
4. Дані записуються в Notion.
5. Стейкхолдер бачить підсумок у Notion-таблиці.
6. Slack-бот надсилає нотифікації, нагадування та щомісячні репорти.

## Основні посилання

- Форма для амбасадорів: https://ambassador-ap-production.up.railway.app
- Tracker-таблиця 2026: https://www.notion.so/66083f8f35264eeca6229a341e21be82?v=364ce9899cb781f99d45000c1ca22b6b&source=copy_link
- Slack-бот: `Program Coins`

## Як працює форма

Форма потрібна для того, щоб амбасадори самостійно подавали свої активності за місяць.

Амбасадор заповнює:

- своє ім'я;
- Slack nickname;
- місяць, за який подається звіт;
- одну або кілька активностей;
- кількість виконань для активностей, де кількість має значення;
- proof-файли або скріншоти для активностей, де потрібне підтвердження;
- додаткові нотатки, якщо потрібно.

У формі одразу показується попередній підрахунок:

- base coins;
- кількість різних активностей;
- bonus coins;
- total coins.

Важливо: підрахунок у формі є зручним прев'ю для амбасадора. Фінальний підрахунок робить backend після сабміту, тому саме дані в Notion є основним джерелом правди.

## Звідки беруться дані

Дані потрапляють у систему з форми, яку заповнює амбасадор.

Після відправки форми система:

1. приймає submission на backend;
2. перевіряє, чи вибрана активність існує;
3. нормалізує кількість, наприклад для активностей без кількості ставить `1`;
4. перевіряє proof-файли для активностей, де вони обов'язкові;
5. рахує coins;
6. оновлює Notion-таблиці;
7. надсилає Slack-нотифікацію адміну/стейкхолдеру.

## Як рахуються coins

Правила активностей:

| Активність | Coins |
| --- | ---: |
| Поширення вакансії Universe у студентських чатах | 5 за 1 |
| Поширення анонсу івентів / стажувань у студентських чатах | 5 за 1 |
| Контакт викладача, який потенційно зацікавлений у співпраці | 10 за 1 |
| Самостійний виступ / лекція у своєму університеті | 50 |
| Співорганізація гостьової лекції у своєму університеті | 20 |
| Поширення вакансії через канал кар'єрного центру / факультету / студради | 10 за 1 |
| Пост для Telegram community / Uni Career Hub | 12 за 1 |
| Екскурсія офісом Universe для одногрупників | 15 |

Бонус: якщо за місяць в амбасадора є 3 або більше різні активності, система додає `+10 coins`.

Total coins = base coins + bonus coins.

## Як працює Notion

У Notion є кілька таблиць. Для стейкхолдера важлива насамперед підсумкова таблиця.

### Основна таблиця для роботи

`Ambassador Program - Monthly Summary`

Тут є один рядок на одного амбасадора за один місяць.

У таблиці видно:

- учасника;
- Slack nickname;
- місяць;
- кількість виконань по кожному типу активності;
- base coins;
- bonus;
- total coins;
- proof-файли;
- дату оновлення.

Це таблиця, по якій зручно дивитися результати місяця, перевіряти нарахування і формувати фінальні підсумки.

### Tracker-таблиця

`Ambassador Program Tracker 2026`

У цій таблиці система оновлює поле `Є активність`.

Як це читати:

- `Є активність` checked означає, що амбасадор уже має хоча б одну активність за відповідний місяць;
- якщо поле порожнє, активності за цей місяць ще немає або вона не була подана через форму.

Для зручного перегляду можна зробити linked view цієї таблиці, відфільтрувати по потрібному місяцю і додати фільтр `Є активність is checked`.

### Технічні таблиці

Їх не потрібно щодня відкривати, але вони потрібні системі:

- `Activity Submissions` - кожна окрема подана активність із proof-файлами;
- `Activity Catalog` - довідник активностей і правил coins;
- `Ambassadors` - список амбасадорів;
- `Automation Log` - лог відправлених автоматичних нагадувань і репортів, щоб система не дублювала повідомлення після рестарту.

## Що робить Slack-бот

Slack-бот називається `Program Coins`.

У Slack App Home є два блоки, розділені divider-ом:

- `Ambassador` - форма, reminder і report для студентської ambassador-програми;
- `EGC` - форма, reminder і report для EGC.

Ambassador працює з власними технічними Notion-таблицями. EGC не створює нову аналітику: веб-форма `/egc` пише в існуючу data source `EGC турнір` на сторінці `EGC аналітика`, тому поточні таблиці й графіки продовжують наповнюватися.

Він має такі функції:

### 1. Нотифікація про новий activity report

Коли амбасадор відправляє форму, бот надсилає повідомлення в admin/report channel.

У повідомленні видно:

- хто подав report;
- за який місяць;
- які активності були додані;
- скільки coins додалося;
- поточний total за місяць.

### 2. Автоматичне нагадування амбасадорам

1-го числа кожного місяця о 09:00 за часовою зоною `Europe/Kyiv` бот надсилає нагадування в ambassador channel.

Нагадування містить:

- місяць, за який потрібно заповнити report;
- посилання на форму;
- посилання на деталі програми.

### 3. Автоматичний monthly report

5-го числа кожного місяця о 09:00 бот надсилає monthly report.

Формат report:

```text
Ambassador coins report - April 2026

@anna - 120 coins
@maksym - 95 coins
@ira - 80 coins
```

У report потрапляють тільки амбасадори, які мають активність за відповідний місяць.

Для EGC report налаштований на 3-тє число. Він надсилає список людей, які заповнили EGC форму за попередній місяць, і кількість коінів до видачі.

### 4. App Home у Slack

У Slack App Home бот має кнопки:

- `Відкрити форму` - відкриває форму за попередній місяць;
- `Отримати звіт` - надсилає звіт користувачу в Slack Messages;
- `Надіслати нагадування` - вручну відправляє нагадування в ambassador channel, якщо воно ще не було відправлене за цей місяць.

## Що потрібно перевіряти стейкхолдеру

Після запуску програми достатньо періодично перевіряти:

1. Чи приходять submissions у `Monthly Summary`.
2. Чи прикріплюються proof-файли.
3. Чи коректно рахуються `Base coins`, `Bonus` і `Total coins`.
4. Чи оновлюється поле `Є активність` у tracker-таблиці.
5. Чи приходять Slack-нотифікації після сабміту форми.
6. Чи прийшло автоматичне нагадування 1-го числа.
7. Чи прийшов monthly report 5-го числа.

## Типові сценарії

### Амбасадор подав одну активність

Система додає кількість у відповідну колонку, рахує base coins, оновлює total coins і надсилає Slack-нотифікацію.

### Амбасадор подав ще одну активність за той самий місяць

Система не створює окремий підсумковий рядок у `Monthly Summary`, а оновлює існуючий рядок цього амбасадора за цей місяць. Кількості й coins додаються до попереднього total.

### Амбасадор має 3 різні активності за місяць

Система автоматично додає bonus `+10 coins`.

### За місяць ще немає submissions

Monthly report покаже `No submissions yet.`

## Що вважати джерелом правди

Основне джерело правди для результатів місяця - `Ambassador Program - Monthly Summary`.

Форма потрібна для збору даних, Slack - для комунікації та нагадувань, а Notion - для збереження, перевірки й фінального підсумку.

## Коли потрібна технічна допомога

До технічної команди варто звертатися, якщо:

- форма не відкривається;
- після сабміту дані не з'являються в Notion;
- не приходять Slack-нотифікації;
- бот не відповідає в App Home;
- автоматичні повідомлення не прийшли 1-го або 5-го числа;
- потрібно змінити правила coins або бонусу.
